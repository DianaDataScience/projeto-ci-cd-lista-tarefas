# Minha Lista de Tarefas

Este é um projeto simples de Desenvolvimento de Sistemas para organizar tarefas.

## Objetivo

A aplicação permite adicionar e excluir tarefas diretamente no navegador.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Relação com a disciplina

O projeto está sendo utilizado na disciplina de DevOps para praticar o fluxo de CI/CD, o uso de branches, commits e pull requests no GitHub.

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Digite uma tarefa no campo de texto.
3. Clique em **Adicionar**.
4. Para excluir uma tarefa, use o botão de exclusão disponível.
